# SpeedBeat

اپلیکیشن ریتم‌ساز اندرویدی با Kotlin، Jetpack Compose و AudioTrack؛ رابط فارسی و تیره، پدهای ضربی، حالت الکترونیک/امبینت و تنظیم BPM با سرعت GPS.

## امکانات
- حداقل Android 8.0 (API 26)
- سرعت GPS در زمان فعال بودن ردیابی و باز بودن برنامه
- نگاشت سرعت به BPM با حساسیت قابل تنظیم
- تولید صدای زنده PCM از طریق `AudioTrack`
- شش پد ضربی و کنترل ولوم
- رابط کاربری فارسی با تم تیره

## ساخت APK
1. Android Studio نسخه جدید را نصب کنید و JDK 17 را انتخاب کنید.
2. پوشه پروژه را از طریق **File > Open** باز کنید.
3. منتظر بمانید Gradle Sync کامل شود.
4. گوشی یا Emulator با Android 8 یا بالاتر را متصل کنید.
5. برای اجرای آزمایشی از **Run** استفاده کنید.
6. برای APK: از منوی **Build > Build Bundle(s) / APK(s) > Build APK(s)** استفاده کنید.
7. APK دیباگ معمولاً در `app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود.

برای انتشار: **Build > Generate Signed App Bundle / APK** را انتخاب و یک keystore امن بسازید. فایل keystore را در GitHub قرار ندهید.

## انتشار در GitHub
مخزن جدید بسازید و کل پوشه را commit کنید. فایل‌های build، `.gradle` و `local.properties` با `.gitignore` کنار گذاشته شده‌اند.

## نکات فنی و محدودیت‌ها
- مجوز مکان فقط هنگام نیاز درخواست می‌شود و داده مکانی به شبکه ارسال نمی‌شود.
- ردیابی GPS در این نسخه در foreground و تا زمانی که صفحه برنامه فعال است طراحی شده است؛ برای ردیابی در پس‌زمینه به foreground service، اعلان دائمی و بررسی الزامات سیاستی نیاز است.
- موتور صدا یک مولد ساده و قابل توسعه است، نه جایگزین موتور حرفه‌ای کم‌تأخیر یا بانک سمپل تجاری. تأخیر و کیفیت به سخت‌افزار وابسته‌اند.
- سرعت GPS ممکن است در فضای بسته یا در حالت سکون در دسترس نباشد. در این حالت BPM آخرین مقدار یا مقدار پیش‌فرض باقی می‌ماند.
- این پروژه به‌عنوان نقطه شروع قابل ساخت ارائه شده است؛ پیش از انتشار نهایی، روی دستگاه‌های واقعی آزمایش عملکرد، مجوزها و کیفیت صوت را انجام دهید.
