# Tempo GPS Playlist

اپلیکیشن اندروید Kotlin برای نگاشت سرعت GPS به سرعت پخش موسیقی.

پیش‌فرض: GPS از 0 تا 20 کیلومتر بر ساعت به سرعت پخش 0.70x تا 1.50x نگاشت خطی می‌شود. برای مثال در 10 km/h سرعت پخش حدود 1.10x است. سرعت کمتر از حداقل روی کمینه و سرعت بیشتر از حداکثر روی بیشینه محدود می‌شود.

امکانات: انتخاب چند فایل صوتی، پخش/مکث/قبلی/بعدی، دریافت سرعت با Google Fused Location Provider، تنظیم و ذخیره بازه GPS و بازه سرعت پخش، خاموش/روشن کردن کنترل خودکار.

اجرا: پروژه را در Android Studio باز کنید، Gradle Sync کنید، روی گوشی واقعی GPS را روشن کنید، پلی‌لیست انتخاب کنید و «شروع GPS» را بزنید.

نکته: این نسخه پایه GPS را وقتی Activity باز است می‌گیرد؛ ردیابی پایدار در پس‌زمینه و MediaSession هنوز اضافه نشده است. GPS در فضای بسته ممکن است نوسان داشته باشد.
