# AutoSpeed Volume — نسخه تکمیل‌شده‌تر

پروژه اندروید Kotlin + Jetpack Compose با داشبورد فارسی، تنظیمات ذخیره‌شونده، نمودار سرعت/صدا و سرویس GPS در foreground.

## اجرا
1. Android Studio را نصب کنید.
2. ZIP را استخراج کنید و پوشه را در Android Studio باز کنید.
3. منتظر بمانید Gradle Sync کامل شود.
4. روی گوشی اندرویدی واقعی اجرا کنید و مجوز موقعیت مکانی و اعلان را تأیید کنید.
5. «شروع تنظیم خودکار صدا» را بزنید. برای توقف از همان دکمه استفاده کنید.

## عملکرد
- داشبورد هر ۷۰۰ میلی‌ثانیه سرعت و درصد صدای ثبت‌شده توسط سرویس را تازه می‌کند.
- حداقل صدا، حداکثر صدا و سرعت مرجع ذخیره می‌شوند و سرویس از آن‌ها استفاده می‌کند.
- سرویس از منحنی خطی استفاده می‌کند: در سرعت صفر حداقل صدا، و در سرعت مرجع حداکثر صدا.
- تغییر صدا با AudioManager روی کانال رسانهٔ سیستم اعمال می‌شود؛ رفتار دقیق آن به دستگاه و نسخه Android وابسته است.

## محدودیت و تست
این پروژه در این محیط با Android SDK ساخته یا روی دستگاه واقعی آزمایش نشده است؛ ممکن است برای نسخه خاص Android یا سازنده گوشی به اصلاح نیاز داشته باشد. اجرای مکان‌یابی پس‌زمینه تحت محدودیت‌های Android، مجوزها و بهینه‌سازی باتری است. بعضی دستگاه‌ها یا تنظیمات سیستم ممکن است کنترل صدای رسانه را محدود کنند. نمودار، منحنی تنظیمات را نمایش می‌دهد، اما صرفاً نمودار تحلیلی است نه ابزار ویرایش نقطه‌ای.
