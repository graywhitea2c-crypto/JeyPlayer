# کنترل هوشمند صدا (Android)

برنامه‌ی ساده‌ی اندروید برای تنظیم صدای رسانه بر اساس سرعت GPS.

## منطق
- زیر ۲۰ km/h: هدف ۲۰٪
- ۲۰ تا ۸۰ km/h: افزایش خطی
- ۸۰ km/h و بالاتر: هدف ۱۰۰٪

## ساخت APK
1. Android Studio را نصب کنید.
2. از مسیر **File > Open** پوشه‌ی `SpeedVolumeAndroid` را باز کنید.
3. اجازه دهید Gradle همگام‌سازی شود (برای این مرحله اینترنت لازم است).
4. از منوی **Build > Build APK(s)** خروجی بگیرید.
5. APK معمولاً در `app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود.

## نکات و محدودیت‌ها
- برنامه صدای رسانه/موسیقی (`STREAM_MUSIC`) را تغییر می‌دهد، نه زنگ یا صدای مکالمه.
- Android صدا را در گام‌های گسسته تنظیم می‌کند؛ بنابراین درصد دقیق روی همه‌ی گوشی‌ها قابل نمایش/اعمال نیست.
- برای ادامه در پس‌زمینه از سرویس پیش‌زمینه نوع location و اعلان دائمی استفاده می‌شود.
- GPS در فضای بسته یا بدون دید آسمان ممکن است دقیق نباشد.
- این پروژه کد منبع است؛ در این محیط فایل APK کامپایل نشده است.
- برای انتشار نهایی باید روی نسخه‌های هدف اندروید، مدیریت خطاهای GPS، مجوز اعلان و محدودیت‌های سازنده آزمایش شود.
