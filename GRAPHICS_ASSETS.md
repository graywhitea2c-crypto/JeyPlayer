# AutoSpeed Volume — Neon graphics assets

Added native Android vector graphics so the artwork stays sharp at every density:
- `res/drawable/autospeed_logo.xml` — app logo (speedometer + music notes)
- `res/drawable/ic_autospeed_foreground.xml` — adaptive launcher icon foreground
- `res/drawable/ic_autospeed_background.xml` — launcher icon background
- `res/mipmap-anydpi-v26/ic_launcher.xml` — adaptive launcher icon definition
- `res/values/colors.xml` — shared neon theme color resources

The manifest now points to the AutoSpeed logo. The vector artwork is editable XML and does not require external image files.
